# ARC-AGI-2 (2025) Development & Winner Benchmark Hub 📈

Welcome to the **ARC-AGI-2** project module. This directory houses the codebase framework, synthetic data generators, and model training pipelines based on the open-sourced strategies of top winners from the **2025 ARC Prize (ARC-AGI-2)**.

---

## 🎯 Benchmark Overview

In March 2025, the ARC Prize Foundation launched **ARC-AGI-2** to replace the original ARC-1 dataset as frontier LLMs began approaching human baselines.

### Key Characteristics
* **1,000+ Granular Tasks**: Over 1,000 novel, fine-grained tasks designed to stress-test high-order abstract reasoning.
* **Human vs. AI Gap**: While human subjects score near ~100%, top AI models dropped sharply (from 50%+ on ARC-1 down to 20–30% on ARC-2).
* **The 2025 Winning Approach (NVIDIA NVARC)**:
  * **Score**: 24% accuracy on the private test set (1st Place).
  * **Core Philosophy**: Shift away from oversized 70B+ models toward a **compact 4B parameter model** combined with massive **synthetic data generation** and **Test-Time Adaptation (TTA)**.

---

## 💡 Winner's Open-Sourced Methodologies

### 1. NVIDIA NVARC Approach (2025 1st Place)
* **Synthetic Task Generator Engine**: Millions of synthetic ARC-style grid pairs were procedurally generated using composable geometric and topological primitives (rotation, symmetry, color mapping, cellular automata).
* **4B Compact Model Backbone**: Pre-trained exclusively on synthetic task transformations. The compact parameter size allowed ultra-fast inference and high-volume test-time sampling.
* **Test-Time Adaptation (TTA)**: At test time, candidate python transformation functions generated by the model were executed against prompt input-output pairs. Only programs passing 100% of prompt examples were selected.

### 2. BARC / The Architects Open-Source Solvers (2024–2025)
* **LLM Program Synthesis**: Fine-tuning Llama-3/Mistral via Unsloth to translate grid pairs into executable Python functions.
* **Prompt Engineering & Sampling**: Generating 1,000+ candidate code solutions per task and executing them in a sandboxed Python runtime.

## 🚀 Open-Sourced Core Implementation

Below are the initial open-source script templates provided in `src/`:

### 1. Synthetic Task Generator (`src/synthetic_generator.py`)
Generates programmatic variations of grid pairs (symmetry, color recoloring, scaling) for training 4B backbones.

### 2. Test-Time Adaptation Evaluator (`src/tta_evaluator.py`)
Executes candidate Python programs against prompt examples to verify 100% correctness before submitting predictions.

## ⚙️ Quick Start

```bash
# 1. Generate Synthetic Training Data
python src/synthetic_generator.py --num_tasks 50000 --output_dir ./data/synthetic/

# 2. Fine-tune 4B Model with Unsloth
python src/train_unsloth.py --model_name "unsloth/Llama-3.2-3B-Instruct" --data_path ./data/synthetic/

# 3. Run Test-Time Adaptation Evaluation
python src/tta_evaluator.py --test_tasks_path ./data/arc-agi-2-test.json --num_samples 1000
```
